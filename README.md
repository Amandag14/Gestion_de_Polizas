# Gestion_de_Polizas
Plataforma web desarrollada para Henríquez y Asociados que permite a los clientes gestionar sus pólizas de seguros, consultar vigencias, fechas de pago y acceder a información detallada, además de contactar a sus agentes. El sistema ofrece una interfaz moderna, intuitiva y responsiva, enfocada en mejorar la experiencia del usuario.
